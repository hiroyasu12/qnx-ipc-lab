# 07のコーディング規約

対象はこのディレクトリのC++17ソース。可読性とOS資源の扱いを明確にするため、以下をローカル規約とする。
MISRA C++:2023を参考とするが、MISRA準拠の宣言ではない。

## 適用する規約

- if / else / for / whileの本体には必ず波括弧を付け、1行に複数の処理を書かない。
- 関数を処理目的で分ける。mainは引数検証・初期化・実行・終了処理の順に読む構成とする。
- 名前は役割を表すものにする。connection_id、receive_id、configuration、progressなどを使う。
- 単位や上限を持つ値は名前付き定数にする。カウンタと共有データには固定幅整数を使う。
- 変更しない引数・ローカル変数にはconstを付ける。データを変更するアクセサーは非constにする。
- 数値の狭小化は避ける。OS APIの戻り値はAPIの型を維持する。MsgSendの戻り値はautoで受ける。
- 入力数値は計算前に範囲を確認する。符号、空白、末尾の文字、0、上限超過を拒否する。
- ヘッダーにはinclude guardを置く。共有構造と関数宣言はヘッダー、OS処理の実装はcppに置く。
- 所有権を持つクラスは内部状態をprivateにし、コピーとムーブを禁止する。
- 新規作成と既存領域への接続はcreate() / attach()で区別する。bool引数で動作を切り替える公開APIは使わない。
- 失敗し得る操作の結果を確認する。boolを返す公開操作にはnodiscardを付ける。
- 通常経路では明示的にclose()して失敗を終了コードへ反映する。デストラクターは取りこぼしに備えて解放を試み、失敗をログに残す。
- Mutexのロック成功後にだけ共有データへアクセスし、ログはアンロック後に出す。
- 受信バッファを構造体ポインタにキャストしない。サイズ確認後、memcpyでローカル変数へ取り出す。
- 動的なC++ヒープ確保、例外、再帰、可変グローバル状態は追加しない。

## OS連携・実験用コードとして残す事項

次は正式なMISRA適合確認時に評価・逸脱記録が必要になる候補であり、承認済みの逸脱ではない。

| 項目 | 現在の扱いと理由 |
| --- | --- |
| QNX / POSIX拡張 | name_attach、MsgReceive、shm_open、mmap、pthreadなど、この実験の対象APIとして使用する |
| mmapのvoid*変換とオブジェクトの生存期間 | OS依存部分としてshared.cppへ集約。同じABIの構造体をマップし、サイズを検証する。ISO C++だけによる保証は主張しない |
| OSのマクロ・予約名 | _IO_CONNECT、_pulse等をシステムヘッダーの定義に従って使用する |
| コマンドラインと文字列走査 | OSが渡すargvを使用。parse_countの走査とAPI文字列にポインタを使用する |
| C形式の入出力・errno | 実験ログとOSエラー表示に使用。printf / fprintfの出力失敗は実験の制御へ反映しない。setvbufや資源操作の失敗は反映する |
| 早期return | 引数検証やAPI失敗のガード節で使用。資源は所有クラスまたは呼び出し元が解放する |
| ビルド日時マクロ | 実験用バイナリの識別に__DATE__ / __TIME__を使う |
| デストラクターの解放結果 | 例外を投げずログに残す。呼び出し元へ通知する経路は明示的なclose()とする |

data()はcreate() / attach()成功後、close()前だけ呼ぶ契約とする。
DONEの送信元認証、重複通知対策、プロセス異常終了時のMutex復旧は、この可読性整理では追加しない。
要求への返信や接続解放に失敗した場合、serverはエラーとして受信ループを終了する。

## 確認方法と限界

build.cmdで以下を有効にし、server / clientを同じ設定でビルドする。

```text
-Wall -Wextra -Wconversion -Wsign-conversion -Wshadow -Wformat=2 -Werror
```

これらは型変換・名前の隠蔽・書式等のコンパイラー検査であり、MISRA検査の代替ではない。
MISRA規約全文とのルール単位の照合、専用静的解析、承認された逸脱記録、外部コンポーネントの評価は未実施。
正式な準拠には適用規約・検証方法・逸脱・開発プロセスを定める必要がある。
根拠：[MISRA Compliance](https://misra.org.uk/compliance/)、[MISRA C++:2023](https://misra.org.uk/product/misra-cpp2023/)。
